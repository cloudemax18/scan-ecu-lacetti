# CheviExplorer Android

Aplicación Android en Kotlin para Chevrolet Lacetti 1.8 LDA (2008), con adaptador KKL 409.1 CH340/CH341 por USB OTG.

Estado inicial: base de conexión USB serie; el protocolo ECU específico y las funciones avanzadas aún deben validarse en vehículo real.


## Distribución y capturas

Consulta [docs/DISTRIBUTION.md](docs/DISTRIBUTION.md) para descargar APK debug, configurar una publicación release firmada, actualizar desde la app y subir capturas de forma autenticada.
